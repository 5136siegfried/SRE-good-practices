---

## 🎯 Objectifs

- Centraliser des **bonnes pratiques** éprouvées dans l'écosystème Cloud / DevOps / SRE
- Fournir des **exemples concrets** : infra, monitoring, sécurité, incident response
- Démontrer une **culture de la fiabilité, du pragmatisme et de la documentation**
- Partager une vision DevSecOps **centrée sur l'impact, l'automatisation et l'humain**

---

## 🧭 Structure

| Dossier | Contenu |
|---------|---------|
| `infra/` | Infrastructure as Code — Terraform, Ansible |
| `observability/` | Dashboards Grafana, Prometheus, alerting, logs |
| `incident-management/` | Gestion d'incidents, postmortems, runbooks |
| `security/` | Secrets, CI/CD sécurisée, threat modeling |
| `tools/` | Scripts et helpers — bash, Python, act |
| `docs/` | Architecture, principes SRE, documentation technique |

---

## 🔧 Stack de référence

- **Cloud** : AWS · GCP · Azure
- **IaC** : Terraform · Ansible
- **Observabilité** : Prometheus · Grafana · Loki · ELK
- **CI/CD** : GitHub Actions · GitLab CI · ArgoCD · act
- **Sécurité** : Vault · Trivy · Snyk · OPA · Kyverno
- **Conteneurs** : Docker · Kubernetes · Helm

---

## 📘 Philosophie SRE

- *"You build it, you run it"*
- Automatisation des tâches récurrentes
- SLOs réalistes, mesurés en permanence
- Postmortems blameless systématiques
- Infrastructure modulaire, versionnée, observable
